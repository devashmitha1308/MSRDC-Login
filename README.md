# MSRDC Employee Login Portal

A responsive, corporate-style employee login page built for the Maharashtra State Road Development Corporation (MSRDC).

## Project Overview

MSRDC Employee Login Portal is a frontend web development project designed to provide a clean, professional, and user-friendly employee login interface.

The design follows a modern enterprise aesthetic using a navy blue, white, and teal color palette.

## Features

- Responsive layout for desktop and mobile devices
- Employee ID input field
- Password input field
- Show/Hide password functionality
- Remember Me checkbox
- Forgot Password assistance message
- Client-side form validation
- Login button loading state
- Secure-access information section
- Smooth transitions and hover effects

## Technologies Used

## How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/devashmitha1308/MSRDC-Login.git
   ```

2. Open the project folder in VS Code.

3. Open `index.html` using Live Server.

4. Explore the login interface in your browser.

## Important Note

This project is a frontend prototype.

Backend authentication, database integration, and actual password-reset functionality are not implemented.
